# 도메인 문서

에이전트가 코드베이스를 탐색하기 전에 읽어야 하는 도메인 문서와 사용 규칙이다.

## 탐색 전에 읽을 문서

- 저장소 루트의 `CONTEXT.md`를 읽는다.
- `CONTEXT-MAP.md`가 존재하면 관련 컨텍스트가 가리키는 `CONTEXT.md`를 읽는다.
- 작업 영역과 관련된 `docs/adr/` 문서를 읽는다.

문서가 없다면 이를 문제로 보고하거나 선제적으로 만들지 않고 작업을 계속한다. 새로운 용어나 결정이 실제로 확정될 때 도메인 모델링 절차로 문서를 추가한다.

## 문서 구조

이 저장소는 단일 컨텍스트 구조를 사용한다.

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

## 용어집 사용

이슈 제목, 리팩터링 제안, 가설과 테스트 이름을 포함해 도메인 개념을 표현할 때 `CONTEXT.md`에 정의된 용어를 사용한다. 용어집에서 피하도록 지정한 동의어로 바꾸지 않는다.

필요한 개념이 용어집에 없다면 프로젝트에서 사용하지 않는 말을 새로 만들고 있는지 먼저 검토한다. 실제 도메인 공백이라면 도메인 모델링 대상으로 기록한다.

## ADR 충돌 표시

제안이나 구현이 기존 ADR과 충돌하면 조용히 덮어쓰지 말고 어떤 ADR과 왜 충돌하는지 명시한다.
