# 트리아지 라벨

스킬에서 사용하는 다섯 가지 표준 역할과 이 저장소의 실제 GitHub 라벨을 연결한다.

| 스킬의 역할 | GitHub 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 관리자의 검토가 필요함 |
| `needs-info` | `needs-info` | 제보자의 추가 정보를 기다림 |
| `ready-for-agent` | `ready-for-agent` | 명세가 완료되어 에이전트가 작업할 수 있음 |
| `ready-for-human` | `ready-for-human` | 사람의 구현 또는 판단이 필요함 |
| `wontfix` | `wontfix` | 작업하지 않기로 결정함 |

스킬이 특정 역할을 언급하면 표의 해당 GitHub 라벨을 사용한다. 실제 저장소의 라벨 명칭을 변경할 때는 오른쪽 열을 함께 수정한다.
