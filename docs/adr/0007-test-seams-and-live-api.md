# 고정된 테스트 seam과 로컬 실 API 검사

자동 테스트는 `SchedulerWorkspace` Interface에서 도메인 동작을 검증하고, 브라우저 사용자 흐름에서는 API 키 입력부터 캐릭터 선택과 대시보드 표시까지 검증한다. 넥슨 호출과 브라우저 저장소는 각각 가짜 넥슨 응답 Adapter와 메모리 저장 Adapter로 교체하며 내부 Implementation이나 호출 횟수를 직접 검사하지 않는다. GitHub CI는 이 결정적인 테스트와 타입 검사, 코드 검사 및 프로덕션 빌드만 실행한다.

실제 NEXON Open API 키는 개발자 컴퓨터에서 명시적으로 실행하는 별도 연동 테스트에서만 사용한다. 캐릭터 목록, 스케줄러 응답 및 CORS의 최소 동작을 확인하되 키, 캐릭터명, 응답 본문, 스크린샷, 영상 또는 추적 파일을 결과물에 저장하지 않는다. 실제 키가 없으면 검사를 건너뛰며 GitHub Actions, Cloudflare 또는 공개 저장소에는 실제 키를 제공하지 않는다.
