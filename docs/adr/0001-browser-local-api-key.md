# 사용자 API 키로 브라우저에서 넥슨 API 직접 호출

서비스는 사용자가 직접 입력한 본인 NEXON Open API 키로 `character/list`와 `scheduler/character-state`를 브라우저에서 넥슨 API에 직접 호출한다. API 키는 서비스 서버, 데이터베이스, 로그, 분석 도구, 오류 수집기 또는 제3자 스크립트로 전달하지 않으며 서버 프록시를 대체 경로로 사용하지 않는다. 넥슨 API가 현재 `x-nxopen-api-key` 헤더의 교차 출처 요청을 허용하므로 이 구조는 기술적으로 가능하며, 운영자의 공용 키와 NEXON Open ID 없이 각 사용자가 본인 계정만 자동 추적할 수 있다.

이 결정은 별도 회원 가입과 서버 측 비밀정보 보관을 없애는 대신 기기 간 동기화를 제공하지 않으며, 브라우저의 XSS·확장 프로그램·공급망 공격으로부터 키를 보호해야 한다. 강한 Content Security Policy를 적용하고 제3자 스크립트를 배제하며 키를 URL, 콘솔, 네트워크 로그 및 서비스 워커 캐시에 포함하지 않는다. CORS 동작은 넥슨이 변경할 수 있고 약관은 제3자 웹의 로컬 키 입력을 명시적으로 설명하지 않으므로, 배포 전 넥슨 문의로 허용 범위를 확인한다.

사용자 편의를 위해 API 키 검증 성공 즉시 키를 현재 브라우저의 `localStorage`에 평문으로 저장하며 별도의 `이 기기에서 기억하기` 선택을 요구하지 않는다. 이 결정은 저장소를 열 수 있는 사람, 같은 출처에서 실행된 악성 스크립트 또는 권한 있는 브라우저 확장 프로그램이 키를 읽을 수 있다는 위험을 수용한다. 키 입력 화면과 설정에서 이 사실을 숨기지 않고 알리며 즉시 키와 모든 로컬 데이터를 삭제할 수 있게 한다. 강한 CSP, 제3자 스크립트 배제, 격리 광고, 의존성 고정 및 보안 검사를 필수 방어책으로 적용한다.

새 키로 교체할 때는 먼저 유효성을 검증하고 사용자 확인을 받은 뒤 기존 계정 데이터와 설정을 삭제한다. 키 오류만으로 로컬 데이터를 자동 삭제하지 않는다.
