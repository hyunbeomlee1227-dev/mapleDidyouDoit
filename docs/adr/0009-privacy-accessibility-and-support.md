# 최소 수집과 접근 가능한 오류 복구 제공

서비스는 별도의 개인정보 안내 페이지를 제공한다. API 키와 앱 데이터가 현재 브라우저에 저장되고 넥슨 API로 직접 전송된다는 점, 운영자가 이를 수집하거나 열람하지 않는다는 점, Cloudflare가 정적 호스팅 과정에서 IP 주소 등 네트워크 정보를 처리할 수 있다는 점을 구분해 설명한다. 쿠키, 자체 분석 및 자동 오류 수집은 사용하지 않는다.

설정의 `모든 데이터 삭제`는 삭제 대상이 API 키, 캐릭터 선택, 항목 설정 및 캐시라는 사실을 확인창에 표시한다. 사용자가 한 번 확인하면 모든 로컬 저장소와 앱 캐시를 삭제하고 첫 설정 화면으로 돌아간다. 문구를 다시 입력하도록 요구하지 않는다.

접근성은 WCAG 2.2 AA를 개발 및 테스트 목표로 삼되 별도의 적합성 인증을 주장하지 않는다. 모든 기능은 키보드로 조작할 수 있어야 하며 드래그 정렬에는 위·아래 이동 버튼을 함께 제공한다. 상태는 색상뿐 아니라 아이콘과 텍스트로 구분하고 충분한 명암비, 터치 영역, 스크린 리더용 이름과 동기화 상태 알림을 제공한다.

오류 문의는 GitHub Issues의 안내된 양식을 사용한다. 앱은 비밀 정보가 없는 짧은 오류 코드만 표시하며 API 키, 원본 API 응답 또는 캐릭터 데이터를 자동 첨부하지 않는다. 이슈 양식 상단에 API 키를 작성하지 말라는 경고를 표시한다.

보안 문제는 공개 Issue로 받지 않는다. 공개 저장소를 만들 때 GitHub의 비공개 취약점 신고 기능을 활성화하고 `SECURITY.md`에서 **Security → Report a vulnerability** 경로를 안내한다.
