# 오래된 캐시와 다중 탭 및 PWA 업데이트를 안전하게 처리

마지막 성공 동기화 후 30일이 지난 API 기반 데이터는 대시보드에 표시하지 않는다. 사용자가 앱을 다시 열면 해당 데이터를 먼저 강제 동기화하고 성공한 최신 데이터로 교체한다. 갱신에 실패하면 `오래된 데이터로 표시할 수 없음`을 안내하되 사용자가 만든 캐릭터 선택, 순서, 숨김 항목과 테마 설정은 유지한다.

같은 브라우저에서 여러 탭이 열려도 한 탭만 넥슨 API 동기화를 수행한다. Web Locks로 동기화 소유권을 조정하고 BroadcastChannel로 진행 상태와 결과를 다른 탭에 전달한다. 이를 지원하지 않는 브라우저에서는 만료 시간이 있는 로컬 잠금으로 중복 호출을 줄인다. 이 기능을 위해 별도 런타임 패키지는 추가하지 않는다.

서비스 워커가 새 PWA 버전을 내려받아도 사용 중인 화면을 강제로 새로고침하지 않는다. `새 버전이 준비되었습니다` 배너와 `지금 적용` 동작을 제공하고 사용자가 선택하거나 모든 앱 탭을 닫은 뒤 다시 열 때 새 버전을 활성화한다.

MVP는 설정, 캐릭터 정보 또는 API 키의 파일 내보내기와 가져오기를 제공하지 않는다. 새 기기에서는 사용자가 API 키를 다시 입력하고 활성 추적 캐릭터를 다시 선택한다.
