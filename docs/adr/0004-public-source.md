# 사용자 API 키 처리 코드를 공개

메했니?의 소스 저장소를 GitHub에 공개하고 사용자 API 키의 입력, 저장, 복호화, 넥슨 API 요청 및 삭제 경로를 누구나 검토할 수 있게 한다. 저장소와 빌드 산출물에는 실제 API 키, 실제 사용자 응답 데이터 및 배포 비밀정보를 포함하지 않으며 이를 검사하는 자동화된 검증을 둔다.

공개한 코드와 Git 이력은 완전히 비공개로 되돌릴 수 없고 공격자도 구현을 분석할 수 있다. 그 대신 사용자가 비밀 API 키를 입력하는 서비스에 필요한 검증 가능성과 신뢰를 제공하며, 보안이 구현 은폐에 의존하지 않도록 한다.
