# 대시보드 광고를 API 키 실행 영역에서 격리

대시보드에는 직접 관리하는 정적 후원 배너 또는 별도 출처의 제한된 `iframe`에서 실행되는 광고만 표시한다. 광고 스크립트를 앱 문서에 직접 설치하거나 사용자 API 키, 로컬 저장소 및 넥슨 API 응답에 접근하도록 허용하지 않는다. 광고 공급자가 부모 문서에 스크립트 설치를 요구하면 연동하지 않는다.

이 구조는 일반적인 광고 연동 선택지를 줄이고 광고 공급자 호환성 검증을 요구하는 대신, 광고 공급망과 앱의 비밀정보 실행 영역을 분리한다. 광고 로드 실패는 대시보드 레이아웃, 자동 추적 및 캐릭터 상태 조회에 영향을 주지 않는다.

MVP에서는 실제 광고를 활성화하지 않는다. 전체 진행 요약 아래에 향후 광고를 연결할 수 있는 슬롯과 비활성 기능 플래그만 준비하며, 광고가 비활성일 때는 자리표시자나 빈 여백을 렌더링하지 않는다.
