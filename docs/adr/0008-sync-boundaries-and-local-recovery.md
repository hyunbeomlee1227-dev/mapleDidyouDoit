# 주기 경계와 부분 실패를 보수적으로 처리

일간 또는 주간 초기화 경계를 지난 이전 주기 캐시는 현재 주기의 완료 집계에서 즉시 제외한다. 새 주기의 스케줄러 조회가 성공하기 전까지 항목을 미완료로 단정하지 않고 `새 주기 확인 중`으로 표시한다. 주기 판정에는 한국 시간을 사용하되 API 응답의 날짜와 분류를 우선하며, 이전 주기의 완료 상태를 새 주기로 이월하지 않는다.

활성 추적 캐릭터의 스케줄러 조회는 동시에 최대 3개까지만 실행한다. `429` 또는 일시적인 서버 오류에는 제한된 점진적 재시도를 적용한다. 일부 캐릭터 조회만 실패하면 성공한 캐릭터의 상태는 갱신하고 실패한 캐릭터에는 마지막 성공 상태와 `동기화 지연`을 표시한다. 전체 동기화를 하나의 원자적 성공이나 실패로 취급하지 않는다.

IndexedDB 구조는 명시적인 버전과 마이그레이션으로 관리한다. 마이그레이션 또는 데이터 읽기가 복구 불가능하게 실패해도 로컬 데이터를 몰래 삭제하지 않는다. 복구 안내와 영향을 받는 범위를 표시하고 사용자가 확인한 경우에만 IndexedDB의 캐릭터 선택, 항목 설정 및 상태 스냅샷을 초기화한 뒤 계정 캐릭터를 다시 불러온다. `localStorage`의 검증된 API 키와 소규모 환경 설정은 유지한다.

모든 화면 하단에는 `Data based on NEXON Open API`와 `넥슨의 공식 서비스가 아닙니다`를 표시한다.
