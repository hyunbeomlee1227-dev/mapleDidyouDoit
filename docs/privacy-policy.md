# 개인정보 안내

메했니?는 회원가입이나 자체 서버 없이 동작하는 브라우저 기반 서비스다.

- 사용자가 입력한 NEXON Open API 키는 검증 성공 후 현재 브라우저의 `localStorage`에 평문으로 저장된다.
- API 키는 사용자 브라우저에서 NEXON Open API로 직접 전송되며 서비스 운영자의 서버, 데이터베이스, 로그 또는 오류 수집기로 전송되지 않는다.
- 캐릭터 선택, 항목 설정과 최근 수행 상태는 현재 브라우저의 IndexedDB에 저장된다.
- 서비스는 쿠키, 자체 방문 분석 및 자동 오류 수집을 사용하지 않는다.
- 정적 사이트를 제공하는 Cloudflare는 서비스 제공 과정에서 IP 주소와 트래픽 관련 네트워크 정보를 처리할 수 있다. 이 처리에는 Cloudflare의 개인정보처리방침이 적용된다.
- GitHub에서 오류를 문의할 때 API 키나 원본 API 응답을 작성해서는 안 된다.
- 설정의 `모든 데이터 삭제` 기능으로 API 키와 모든 로컬 데이터를 삭제할 수 있다.

실제 공개 전에 운영자 연락 수단, 시행일과 Cloudflare 개인정보처리방침 링크를 추가한다.
